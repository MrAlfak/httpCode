# Code of Conduct

We want httpCode to be a useful, welcoming project for developers, researchers, students, and maintainers.

## Our standards

Be respectful, technical, and constructive. Good contributions:

- focus criticism on code, data, sources, or behavior rather than people;
- include evidence when correcting status-code data;
- welcome contributors with different levels of experience;
- avoid harassment, discrimination, personal attacks, spam, and intentionally disruptive behavior;
- respect security-reporting guidance and do not publish exploit details irresponsibly.

## Enforcement

Project maintainers may edit, hide, reject, or remove contributions and interactions that violate these standards.

For sensitive conduct or security concerns, use GitHub's private reporting features when available instead of opening a public issue.

This project also supports the principles of the [Contributor Covenant](https://www.contributor-covenant.org/).
